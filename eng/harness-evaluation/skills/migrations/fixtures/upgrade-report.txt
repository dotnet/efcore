Scenario
--------
A project created on EF Core 9.0.3 has a Customer entity with a required struct Address complex property. After updating the tools and runtime to EF Core 10, `dotnet ef migrations add CheckUpgrade` emits a migration although the application model was not changed.

  IsNullable: false
  OldColumn.ClrType: System.Int32

The legacy snapshot contains no explicit required/optional call for Customer.Address. The application model and database schema are otherwise unchanged.
