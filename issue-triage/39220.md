## Issue

[dotnet/efcore#39220](https://github.com/dotnet/efcore/issues/39220) reports a regression where a correlated `SelectMany` over a `GroupBy` aggregate with `DefaultIfEmpty()` changes from a `LEFT JOIN` to `OUTER APPLY`. SQLite does not support `APPLY`, so the query that translated in EF Core 9 and 10.0.0-rc.1 fails in later versions.

- Type: **Bug**
- Labels applied: `area-query`, `customer-reported`, `regression`
- Security concern: None apparent.

using System;
using System.Linq;
using Microsoft.EntityFrameworkCore;

using var db = new Ctx();

var sub = from t in db.Transactions
          group t.Amount by t.UserId into g
          select new { g.Key, Amount = g.Sum() };

var query = from u in db.Users
            from t in sub.Where(j => j.Key == u.Id).DefaultIfEmpty()
            select new { u.Id, Amount = (int?)t.Amount ?? 0 };

Console.WriteLine(query.ToQueryString());

public class User { public int Id { get; set; } public string Name { get; set; } }
public class Transaction { public int Id { get; set; } public int UserId { get; set; } public int Amount { get; set; } }

public class Ctx : DbContext
{
    public DbSet<User> Users => Set<User>();
    public DbSet<Transaction> Transactions => Set<Transaction>();

}
